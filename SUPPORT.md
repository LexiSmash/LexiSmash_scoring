# Support

- **A value looks wrong?** Open a Pull Request (see CONTRIBUTING.md), or an Issue with the **Score correction** form.
- **A question about how scoring works in the game?** Open an Issue — or read the game's [Letter Scores page](https://lexismash.it/letter-scores.html).
- **A problem with the game itself?** Report it in the [LexiSmash community repository](https://github.com/LexiSmash/.github/issues).
- **Anything else:** f.rombaldoni@campus.uniurb.it
