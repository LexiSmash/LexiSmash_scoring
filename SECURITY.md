# Security Policy

This repository contains only static data (JSON files) and a static page (HTML/CSS/JS) served by GitHub Pages: there's no server, no account and no personal data here.

If you still find a security problem — for example a way to inject script through the Explorer — please **don't open a public Issue**. Write instead to **f.rombaldoni@campus.uniurb.it** with a short description and the steps to reproduce it. You'll get an answer as soon as possible.

Problems with the game itself (lexismash.it) can be reported at the same address.
