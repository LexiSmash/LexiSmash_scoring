# Code of Conduct

LexiSmash is a party game: this repository should feel like a friendly table, not an argument.

## Our standards

- Be kind and patient, especially with people contributing for the first time.
- Discuss values and sources, not people.
- Accept that a proposal can be declined, and explain your reasons when you decline one.
- Use English in Issues and Pull Requests when you can, so every reviewer can follow; if you can't, write in your own language — someone will help.

## Not acceptable

- Insults, harassment, discriminatory jokes or personal attacks.
- Publishing other people's private information.
- Spam, or repeatedly reopening a topic that has already been decided without new arguments.

## Enforcement

The maintainer can edit, hide or remove comments, Issues and Pull Requests that break these rules, and can block repeat offenders. To report a problem privately, write to **f.rombaldoni@campus.uniurb.it**.
