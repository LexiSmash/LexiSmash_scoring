# Data licenses and notes

## Letter values (`scoring/*.json`)

The files in `scoring/` list how many points each letter is worth in LexiSmash, per language and per scoring system. A list of letter values is factual information; to remove any doubt, these files are released under **CC0 1.0 Universal** like the rest of the repository.

- **`scrabble`** — the letter values of the official Scrabble tile distribution for each language, entered and checked by hand. *Scrabble* is a registered trademark of its respective owners (Hasbro, Inc. in the USA and Canada; Mattel, Inc. elsewhere). This project is **not affiliated with, sponsored or endorsed by** them; the name is used only to say which well-known set of values is being followed.
- **`frizzy`** ("Standard Scarabeo", Italian only) — the letter values of *Scarabeo*, the crossword board game long sold in Italy as an alternative to Scrabble, with its own values (deliberately different from Scrabble's). It was not invented for LexiSmash. *Scarabeo* is a trademark of its respective owners; this project is not affiliated with, sponsored or endorsed by them.

## Letter sets (`alphabets/*.json`)

The letters the game can draw (`vocals`, `consonants`) for each language: original work for LexiSmash, released under **CC0 1.0 Universal**.
